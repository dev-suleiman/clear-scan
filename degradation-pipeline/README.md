# ClearScan — Synthetic Degradation Pipeline

This pipeline takes clean chest X-ray images and produces paired clean/degraded versions for training the ClearScan quality assessment and enhancement models. Every clean image gets resized to 512×512 and saved; then N degraded variants are generated by randomly applying one of six degradation methods that simulate real-world X-ray capture problems.

---

## What each degradation type simulates

| Degradation | Real-world cause |
|---|---|
| `gaussian_blur` | Patient movement during the exposure — the chest and ribs shift while the X-ray plate is open, smearing fine detail. |
| `gaussian_noise` | Electronic noise from the detector or amplifier circuitry, especially prominent at low radiation doses or high detector sensitivity. |
| `poisson_noise` | Quantum (photon-counting) noise — at low photon counts each pixel's measured value varies randomly around the true value. |
| `underexposure` | Insufficient radiation dose reaching the detector: the generator settings were too low, the patient was unexpectedly thick, or the exposure time was cut short. |
| `contrast_compression` | Incorrect windowing or a poorly calibrated detector compresses the dynamic range, washing out the difference between tissue densities. |
| `combined` | A realistic multi-fault scenario: two of the above are chained (e.g. underexposed **and** noisy), representing compounding capture problems. |

## Setup

```bash
cd degradation-pipeline

# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

# Install dependencies
pip install -r requirements.txt
```

---

## Running the pipeline

### Default run (processes data/raw/, 3 variants per image)

```bash
python scripts/generate_degraded.py
```

### Run on a different folder of images

```bash
python scripts/generate_degraded.py \
    --input_dir path/to/your/images/ \
    --output_dir path/to/output/ \
    --samples_per_image 5
```

### Arguments

| Argument | Default | Description |
|---|---|---|
| `--input_dir` | `data/raw/` | Folder containing source images (.png, .jpg, .jpeg, .bmp) |
| `--output_dir` | `data/synthetic_pairs/` | Root output folder; `clean/` and `degraded/` are created inside |
| `--samples_per_image` | `3` | Number of degraded variants to generate per source image |

---

## Output

- `data/synthetic_pairs/clean/` — 512×512 grayscale copies of source images (original filenames preserved)
- `data/synthetic_pairs/degraded/` — Degraded variants named `{stem}_deg_{N}_{type}.png`
- `data/synthetic_pairs/pairs_manifest.csv` — One row per pair with columns:
  - `clean_path` — relative path to the clean image
  - `degraded_path` — relative path to the degraded image
  - `degradation_type` — which degradation was applied
  - `parameters_used` — the specific random parameter values used (e.g. `sigma=2.1`)

---

## Notes

- Variety is enforced: the same degradation type is never applied twice in a row to the same image.
- `combined` picks two of the five base degradations at random and chains them.
- All images are loaded as **grayscale** and resized to **512×512** using bicubic interpolation before any degradation is applied.
- Pixel values are processed in float64 internally to avoid rounding errors, then converted back to uint8 for storage.
